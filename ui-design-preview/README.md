# UI 设计预览模块

用于快速预览 `Web PC / H5` 方向的 UI，不直接参与正式业务构建。

当前方向已经从“手机预览 + 底部 tab”切换为“PC 工作台优先”。

当前能力：

- PC 工作台高保真预览
- 一级导航切换：首页 / 内容 / 学习 / 我的
- 左侧控制区 + 右侧桌面预览区
- 固定 `1440 × 960` 设计基准
- 预览区内支持导航、学段、学科、章节、场景、右侧面板交互
- 内置本地优先 / 同步状态演示

## 启动方式

```bash
cd ui-design-preview
python3 -m http.server 57000
```

访问：

- `http://127.0.0.1:57000`

## 当前设计结论

- 以 `PC` 为核心做工作台布局
- `H5` 后续只做响应式折叠适配
- 不再使用底部 tab 作为主导航
- 结构模型采用：
  - 顶栏导航
  - 左侧课程结构
  - 中间主画布
  - 右侧上下文面板

## 说明

- 当前仅用于 UI 设计预览
- 当前预览画布按 `1440 × 960` 固定
- 当前默认先演示 `内容工作台`
- 后续 Web 正式实现时，可按这里的视觉与信息架构继续拆到 `web-app/`
