# UI 设计预览模块

用于快速预览小程序的视觉方向与 4 tab 信息架构，不直接参与正式业务构建。

当前能力：

- 3 套视觉方向切换
- 4 个 tab 页面切换
- 手机容器内可点击交互预览

## 启动方式

```bash
cd ui-design-preview
python3 -m http.server 57000
```

访问：

- `http://127.0.0.1:57000`
