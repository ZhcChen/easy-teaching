# uni-app 初始化规划

## 当前结论

- 前端主模块采用 `uni-app`
- 技术栈采用 `Vue 3 + TypeScript`
- 仓库按多模块组织，但模块直接放在仓库根目录，不增加 `apps/` 这一层

## 目录约定

当前阶段先落以下结构：

- `miniprogram/`：微信小程序主模块
- `docs/`：规划、方案、经验沉淀

为后续扩展预留：

- `services/`：后续服务端模块
- `packages/`：后续公共模块

## 选型理由

当前项目优先目标是尽快落地微信小程序，同时保留后续扩展到更多小程序平台的空间。`uni-app` 更适合当前阶段，原因如下：

- 基于 `Vue` 语法和小程序 API，适合快速推进业务开发
- 对国内多小程序平台支持较完整
- 后续如需扩展到 H5、App 或其他小程序平台，迁移成本较低

3. 在生成后的项目基础上补充首页、基础路由和全局样式
