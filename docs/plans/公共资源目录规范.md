# 公共资源目录规范

## 目标

在仓库根目录统一维护可被多个模块复用的资源母版，避免资源分散、重复维护、命名混乱。

当前公共资源根目录为：

- `shared-assets/`

当前面向的模块包括：

- `web-app/`
- `asset-studio/`
- `wechat-miniprogram/`
- `services/`（后续）
- `packages/`（后续）

同时要兼容后续扩展到物理、数学、化学，以及偏记忆教学的人文内容。

## 适用范围

应该放入 `shared-assets/` 的内容：

- 品牌资源：logo、图标基准稿、标准色、品牌插图
- 通用插画：跨模块复用的背景图、装饰图、教学通用视觉元素
- 学科公共素材：按学科沉淀但不绑定某个具体模块的底稿
- 资源说明文档：资源用途、来源、导出说明、授权说明

不应该放入 `shared-assets/` 的内容：

- 某个单独模块私有页面图片
- 构建产物、编译缓存、压缩包
- 临时截图、调试文件、一次性草稿
- 只能服务某个页面且没有复用价值的资源

## 目录约定

当前目录约定：

```text
shared-assets/
├─brand/
│ ├─logo/
│ ├─palette/
│ └─icons/
├─illustrations/
│ ├─marketing/
│ └─teaching/
└─subjects/
  ├─physics/
  ├─math/
  ├─chemistry/
  └─humanities-memory/
```

现阶段已落地：

- `shared-assets/brand/`
- `shared-assets/illustrations/`
- `shared-assets/subjects/`

说明：

- `brand/` 存放品牌识别系统资源
- `illustrations/` 存放跨学科、跨模块可复用插画
- `subjects/` 存放带有学科属性但仍可跨模块复用的素材母版

## 命名规范

- 目录名统一使用英文小写，采用 `kebab-case`
- 文件名统一使用英文小写，采用 `kebab-case`
- 不使用 `final`、`最终版`、`新版2` 这类不可维护命名
- 稳定资源使用稳定文件名，例如 `logo-mark.svg`
- 方案探索稿放到单独子目录，例如 `explorations/2026-07/`

示例：

- `shared-assets/brand/logo/logo-mark.svg`
- `shared-assets/subjects/physics/mechanics/projectile-motion-diagram.svg`

## 文件格式规范

- 矢量图优先使用 `SVG`
- 位图优先使用 `PNG` 或 `WebP`
- 配置类资源优先使用 `JSON`
- 说明文档使用 `Markdown`

原则：

- `shared-assets/` 优先保存母版和源稿
- 某个业务模块需要特定尺寸时，再从母版导出
- 如必须提交导出位图，应在同目录说明用途与来源

## 使用规范

### 单一母版原则

- 同一份品牌资产只维护一份母版
- 业务模块不重复维护各自的“主稿”
- 模块内若需要拷贝导出稿，要能追溯到 `shared-assets/` 的母版

### 学科无关资源优先上收

如果某个资源未来明显会被多个学科或多个模块复用，应优先放到 `shared-assets/`，不要先塞进业务模块里。

### 模块私有资源留在模块内

例如：

- 小程序首页 banner 只在 `wechat-miniprogram/` 使用
- 某个实验页临时贴图只服务一个实验

这类资源保留在模块自己的 `assets/` 内，不要上收到公共资源目录。

## 学科素材组织建议

后续 `subjects/` 下建议按“学科 -> 主题 -> 资源”组织：

```text
shared-assets/subjects/
├─physics/
│ └─mechanics/
├─math/
│ └─geometry/
├─chemistry/
│ └─molecular-structure/
└─humanities-memory/
  └─timeline/
```

这样做的目的：

- 不把公共资源设计成只服务物理
- 数学、化学、人文记忆类内容都能自然扩展
- 后续服务端、官网、管理后台也能直接复用

## 品牌资源要求

`shared-assets/brand/` 下的资源至少要满足：

- 有明确用途说明
- 有源稿与稳定命名
- 有深色/浅色或单色适配预留
- 有后续导出为小程序、官网、后台所需尺寸的空间

当前首版品牌资源：

- `shared-assets/brand/logo/logo-mark.svg`
- `shared-assets/brand/logo/logo-horizontal.svg`
- `shared-assets/brand/logo/logo-monochrome.svg`

当前品牌图标导出补充要求：

- 业务使用的 PNG 导出稿默认保持透明背景
- 不在导出稿外围保留环境阴影或投影
- 避免在后台上传、桌面图标、深浅主题切换时出现白边、灰边或脏边

## 协作更新规则

当出现以下情况时，需要同步更新文档：

- 新增 `shared-assets/` 一级目录
- 引入新的品牌资源类别
- 学科素材组织方式发生变化
- 公共资源命名规则发生变化

至少同步更新：

- `shared-assets/README.md`
- 本文档 `docs/plans/公共资源目录规范.md`
