# UI 设计预览模块规划

## 当前状态

该模块已经从“手机态预览”切换为“PC 工作台预览”。

原因：

- 当前前端主路线已经改为 `Web App`
- 产品需要以 `PC` 为核心组织信息与交互
- `H5` 只作为后续响应式适配，不再反向主导整体布局
- 不再采用底部 `tab` 作为一级主导航

## 目标

在仓库根目录保留一个独立的 UI 预演模块，专门服务：

- Web 端整体信息架构确认
- PC 端高保真布局试验
- 内容工作台交互预演
- 后续 H5 折叠适配的视觉参考

## 模块定位

模块仍为：

- `ui-design-preview/`

该模块不是正式业务端，而是设计草模与交互预览模块。

当前优先服务：

- `web-app/`

## 当前范围

本阶段不再做多套手机风格对比，而是先收敛到一套更明确的 `PC 工作台` 方向。

当前优先预览：

1. `内容工作台`
2. `首页总览`
3. `学习中心`
4. `个人工作区`

其中核心优先级最高的是：

- `内容工作台`

## 页面结构

当前预览页采用：

```text
页面
├─左侧控制区
│ ├─一级导航切换
│ ├─学段切换
│ ├─学科切换
│ ├─当前方案说明
│ └─H5 适配说明
└─右侧预览区
  └─PC 桌面工作台
    ├─顶栏导航
    ├─左侧课程结构
    ├─中间主内容画布
    └─右侧上下文面板
```

## 核心设计原则

### 1. PC 优先

- 以桌面工作台为核心布局
- 允许更高的信息密度
- 支持多区并列显示
- 优先让“看内容 + 做交互 + 看说明”同时发生

### 2. H5 后适配

H5 不再反向决定整体布局，只做折叠适配：

- 顶栏保留一级入口
- 左侧课程结构折叠为抽屉
- 右侧上下文面板下沉到正文下方
- 不使用底部一级 tab

### 3. 内容页优先

因为这个产品本质上更像“教学内容工作台”，所以当前优先设计：

- 内容页

而不是先做一个纯展示型首页。

## 交互要求

### 左侧控制区

至少支持：

- 一级导航切换
- 学段切换
- 学科切换

### 右侧 PC 工作台内交互

至少支持：

- 顶栏导航切换
- 左侧章节切换
- 内容场景切换
- 右侧说明 / 笔记 / 同步区切换
- 模拟同步状态变化

## 视觉方向

当前不再保留 3 套分散风格，而是先统一收敛为一套：

- 深色桌面工作台基底
- 轻科技但不过度炫技
- 重点突出可读性、层级和内容结构
- 适合后续承接物理、数学、化学与记忆教学

## 技术实现建议

模块文件保持：

```text
ui-design-preview/
├─index.html
├─styles.css
├─app.js
└─README.md
```

当前实现方式：

- `index.html`：左控右预览骨架
- `styles.css`：PC 工作台布局与组件样式
- `app.js`：状态管理、视图切换与交互模拟
- `README.md`：启动方式与模块说明

## 数据组织建议

当前轻量状态对象建议包含：

- `view`
- `stage`
- `subject`
- `chapter`
- `scene`
- `contentType`
- `contextTab`
- `syncState`

这样后续继续扩展内容工作台时，不需要重写整体结构。

## 启动方式

模块继续支持：

```bash
cd ui-design-preview
python3 -m http.server 57000
```

访问地址：

- `http://127.0.0.1:57000`

当前预览基准：

- 设计画布：`1440 × 960`
- 结构模型：`顶栏 + 左导航 + 主画布 + 右面板`

1. 从手机容器切换到 PC 桌面工作台
2. 从底部 tab 导航切换到顶栏导航
3. 从多套风格对比切换到单一收敛方向
4. 从“小程序思路”切换到“Web PC 优先思路”
