# UI 设计预览模块规划

## 目标

在仓库根目录新增一个专门用于可视化查看 UI 方案的模块，服务于前端视觉方向确认与交互预演。

该模块特点：

- 独立于 `wechat-miniprogram/`
- 只使用原生 `HTML + CSS + JS`
- 通过本地 Python HTTP 服务启动
- 固定访问端口为 `57000`
- 左侧区域为操作与说明
- 右侧区域为手机预览
- 主体是一个可交互的手机容器
- 固定按 `iPhone 12 Pro Max` 尺寸预览

## 模块定位

建议新增根目录模块：

- `ui-design-preview/`

该模块不是正式业务端，而是设计预览与交互草模模块，用于：

- 预览 4 tab 信息架构
- 快速比较不同 UI 风格
- 给后续 Web App 实现提供视觉基准

## 当前范围

本阶段只做方案 B：多套视觉方向对比。

首批落 3 套方向：

1. 明亮教育卡片风
2. 学习路径风
3. 轻科技实验室风

## 页面结构

预览页建议采用单页结构：

```text
页面
├─左侧控制区
│ ├─风格切换
│ ├─页面切换
│ ├─当前方向说明
│ └─设备规格说明
└─右侧预览区
  └─手机容器
    ├─iPhone 12 Pro Max 固定尺寸
    ├─状态栏
    ├─页面内容
    └─底部 4 tab
```

## 交互要求

### 顶部切换

顶部至少支持：

- 设计风格切换
- 页面切换

建议页面切换包括：

- 首页
- 内容
- 学习
- 我的

### 手机容器内交互

手机容器内 UI 需要可点击，不只是静态图。

至少支持：

- 点击底部 tab 切换页面
- 点击首页学段卡切换当前学段
- 点击内容页筛选项切换状态
- 点击学习页记录卡片切换选中态
- 点击我的页同步按钮模拟同步反馈

## 视觉方向要求

### 方向一：明亮教育卡片风

- 白底为主
- 大量留白
- 柔和圆角卡片
- 蓝色为品牌主色
- 更适合首页、内容页、我的页

### 方向二：学习路径风

- 路径节点感更强
- 进度、阶段、连续学习感更强
- 更适合学习页和首页推荐区

### 方向三：轻科技实验室风

- 引入轻量网格、渐变和数据面板感
- 保持可读性，不做重度深色科技风
- 更适合实验类和可视化内容表达

## 技术实现建议

模块文件建议：

```text
ui-design-preview/
├─index.html
├─styles.css
├─app.js
└─README.md
```

实现方式：

- `index.html`：页面骨架与手机容器
- `styles.css`：三套主题与组件样式
- `app.js`：状态管理、切换与交互模拟
- `README.md`：启动方式与用途说明

## 数据组织建议

前端状态可先使用一个轻量本地状态对象，包含：

- `theme`
- `page`
- `stage`
- `subject`
- `activeTab`
- `syncState`

这样后续如果要继续扩展更多页面或更多风格，不需要重写结构。

## 启动方式

模块需支持以下本地启动方式：

```bash
cd ui-design-preview
python3 -m http.server 57000
```

访问地址：

- `http://127.0.0.1:57000`

当前预览基准：

- 机型：`iPhone 12 Pro Max`
- 设计画布：`428 x 926`

## 执行步骤

1. 新增规划文档
2. 创建 `ui-design-preview/` 模块骨架
3. 实现三套视觉风格切换
4. 实现 4 tab 交互预览
5. 用本地 Python 服务启动
6. 验证页面可访问、可点击、可切换

## 当前产出标准

本轮完成后应具备：

- 可本地访问的 UI 预览模块
- 可切换 3 套视觉方向
- 可切换 4 个 tab 页面
- 可点击的主要交互演示
- 可作为后续小程序 UI 实现参考
