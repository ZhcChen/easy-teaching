# Asset Studio

用于预览和对比教学资产设计稿的独立模块。

当前重点：

- 让资产可以被直观看到
- 对比不同颜色方案
- 看深色 / 亮色 / 缩略场景下的效果
- 为 `web-app/` 提供接入前的确认依据

## 启动

```bash
cd asset-studio
npm install
npm run dev
```

访问：

- `http://127.0.0.1:57002`

## 当前首批预览资产

- `shared-assets/subjects/physics/mechanics/motion-track/cart/`
